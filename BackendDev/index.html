BACKEND BASICS

What happens when someone uses your app?

A backend is the part of an app that receives requests, applies rules, stores information, and sends a response.

1 · Request

A phone or website asks for something, such as GET /products.

2 · Route and logic

Your backend chooses a route, checks the request, and decides what should happen.

3 · Data

The backend reads or changes records. Starters use temporary memory; real services need a database.

4 · Response

The backend returns a status and JSON, which the app can display.

Get your backend online

BackendDev creates and checks code. To host a live API, deploy your exported project on a hosting provider such as Render, then set its start command and environment variables.

  1. Choose a project and export its files.
  2. Create a web service in your hosting provider and connect your Git repository.
  3. Set a build/start command and required environment variables.
  4. Deploy, then paste the public URL into the API tester.
