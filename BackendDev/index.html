Get your backend online

BackendDev creates and checks code. To host a live API, deploy your exported project on a hosting provider such as Render, then set its start command and environment variables.

  1. Choose a project and export its files.
  2. Create a web service in your hosting provider and connect your Git repository.
  3. Set a build/start command and required environment variables.
  4. Deploy, then paste the public URL into the API tester.
